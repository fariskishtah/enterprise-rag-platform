# Recruiter Demo Script (60-Second Elevator Pitch)

Targeted script for technical recruiters and hiring managers.

---

## 60-Second Pitch Script

*"Hi, I'm Faris, and I built **EnterpriseRAG**—a local-first multimodal knowledge intelligence platform designed to keep source evidence visible across documents, video, and scanned media.*

*Core file workflows run with local Qwen2.5-0.5B, sentence-transformers, faster-whisper, and FAISS components; optional YouTube import still depends on third-party availability.*

*Key engineering highlights:*
1. **Grounding controls**: Sentence-level claim-support checks and citations make unsupported output visible; they do not guarantee model correctness.
2. **Multimodal & Multilingual**: Supports scanned PDFs via OCR, structured tables via pdfplumber, video timestamp citations, and Arabic cross-lingual QA.
3. **Constrained-host design**: Consolidated multi-prompt Compare into one model call and added a bounded process queue to reduce memory pressure.
4. **Public-demo architecture**: Includes evaluation and feedback views, signed demo sessions, upload quotas, cleanup and backup tooling, and a multi-stage Docker deployment.

*Check out the code and the deployment documentation on GitHub."*
