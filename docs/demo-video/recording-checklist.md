# Recording Checklist

- [ ] Clean browser window at 1440x900 resolution with no external bookmarks.
- [ ] Run `.venv/bin/uvicorn app.main:app` with `APP_RUNTIME_PROFILE=low_memory`.
- [ ] Seed workspace data (`POST /api/v1/demo/seed`).
- [ ] Record high-quality 60fps video with clear audio input.
- [ ] Verify mouse movements are smooth and citations open cleanly.
- [ ] Test video playback seeking when clicking transcript timestamps.
