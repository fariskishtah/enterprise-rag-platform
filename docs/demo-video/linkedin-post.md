# LinkedIn Post Announcement Template

🚀 Excited to share **EnterpriseRAG**—a local-first multimodal knowledge intelligence platform designed for evidence-aware AI research!

Key highlights:
- 📄 **Multimodal RAG**: PDF, DOCX, scanned PDFs (OCR), tables, audio & video.
- 🎬 **Video Intelligence**: Interactive Whisper transcript timestamps sync with video playback.
- 🌍 **Multilingual**: Cross-lingual Arabic & English QA with dynamic RTL interface.
- ⚡ **Constrained-host Optimised**: Consolidated multi-prompt Compare into one model call and added bounded process concurrency.
- 📊 **Evaluation & Feedback**: Integrated Evaluation Dashboard and answer feedback pipelines.
- 🐳 **Docker & HF Spaces**: Deployable as a single-container Hugging Face Docker Space.

Built with open-source components including Python, FastAPI, React, TypeScript, Qwen2.5, LangChain, FAISS, and Whisper.

🔗 GitHub: https://github.com/fariskishtah/enterprise-rag-platform
Deployment steps: see the repository README and AWS deployment guide.
