# EnterpriseRAG 2-Minute Demo Script

A structured 120-second walkthrough script showcasing the core product workflows.

---

## Script Timeline

| Time | Visual Action | Voiceover Audio |
| :--- | :--- | :--- |
| **00:00 - 00:15** | Open Hero Dashboard (`/`) showing metrics & knowledge base scope. | *"Welcome to EnterpriseRAG, an end-to-end multimodal knowledge intelligence platform designed for local-first, evidence-aware research."* |
| **00:15 - 00:30** | Create a Knowledge Base ("Corporate Policy 2026") and upload a PDF document. | *"We start by creating a knowledge base and uploading a PDF contract. Text extraction, sentence chunking, and vector indexing run as a bounded background workflow."* |
| **00:30 - 00:45** | Navigate to Chat page (`/chat`). Ask a grounded policy question. | *"Asking a question retrieves relevant context via hybrid dense and BM25 search. Clicking a citation jumps directly to the source passage with verifiable claim support."* |
| **00:45 - 01:00** | Ask an unsupported question out of domain. | *"If information is missing, EnterpriseRAG can state that evidence is insufficient. This reduces unsupported-answer risk, but citations and source material still need review."* |
| **01:00 - 01:15** | Navigate to Intelligence page (`/intelligence`). Run a Document Comparison. | *"Using consolidated single-call intelligence, we compare multiple sources across common themes, differences, and limitations. CPU completion time varies by host and source size."* |
| **01:15 - 01:30** | Open Video page (`/video`). Load video transcript and click a timestamp. | *"EnterpriseRAG also indexes media. Clicking a timestamp in the interactive transcript jumps video playback directly to that exact moment."* |
| **01:30 - 01:45** | Show the active engine on Settings and explain the environment configuration. | *"The deployment can select either the Custom Hybrid Engine or the LangChain LCEL course engine through configuration; Settings shows the active engine."* |
| **01:45 - 02:00** | Open Evaluation Dashboard & GitHub repo link. | *"With measured-on-demand evaluation, Arabic cross-lingual support, and documented container deployment, EnterpriseRAG demonstrates production-minded engineering with explicit limits."* |
