# Security policy

## Reporting a vulnerability

Do not put exploit details, credentials, uploaded content, cookie files, or personal data in
a public issue. Use GitHub's private vulnerability-reporting option on the repository's
**Security** tab when it is available. Otherwise, contact the repository maintainer through
the [GitHub profile](https://github.com/fariskishtah) and request a private reporting channel.

This portfolio project does not promise a response time, security SLA, penetration-test
coverage, or a bug-bounty payment.

## Supported code

Security fixes target the current `main` branch and the most recent published release. Old
demonstration deployments and unmaintained tags should not be treated as supported.
